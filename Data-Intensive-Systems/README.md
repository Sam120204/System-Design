# Data-Intensive Systems

Notes on data models, system design trade-offs, and large-scale product cases. A suggested reading path:

1. [Design Is All About Trade-offs](design-is-all-about-trade-off.md) — start with requirements and the cost of each design choice.
2. [NoSQL](NoSQL.md) and [Web Application Frontend Architecture](Web应用前端架构-状态管理与扩展组件.md) — review data access, transactions, sessions, and application components.
3. [Design Instagram](<User Generated Content case (ins).md>) — practice media upload and feed delivery.
4. [Design TikTok](<案例分析 - Design TikTok.md>) — extend that model to video processing, storage, and playback.
5. [Design a News Aggregation System](<design news aggregator system.md>) — examine ingestion, clustering, ranking, and feed delivery.

The diagrams used by the Instagram and TikTok notes are in [`assets/`](assets/).
